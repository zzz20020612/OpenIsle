# OpenIsle 三系统一体化与机构风格界面设计

## 目标

把投稿、已有文献知识处理、人工评分排名组织成一个用户可理解的 OpenIsle 产品。用户只登录一次、只使用 OpenIsle 页面，不需要知道功能来自哪套源码，也不通过外部页面完成核心操作。

本阶段先完成统一界面和核心链路，允许原文献处理引擎保留少量自身缺陷；不为了“代码形式统一”重写已经可工作的算法。

## 系统边界

### OpenIsle

- 作为唯一公开入口，负责注册、登录、权限、导航和统一页面。
- 保存投稿论文及其草稿、修订、初筛和详情状态。
- 原生承载人工评分规则、评分任务、评分结果和排行榜。
- 展示已有文献库，提供采集、PDF 处理、知识提取、检索和任务重试操作。
- 通过后端适配层调用文献处理引擎，对前端隐藏服务地址和数据结构差异。

### 文献处理引擎

- 保留第一位协作者 Python 系统中的在线元数据采集、开放 PDF 下载、全文解析、LLM 提炼、检索和任务处理能力。
- 作为 Docker 内部服务运行，不再承担面向最终用户的独立界面。
- OpenIsle 后端负责鉴权、审计、错误归一化和数据映射。

### 评分排名

- 使用已经写入 OpenIsle 后端和前端的人工评分、任务分配、利益冲突声明、积分与等级、排行榜实现。
- 已有文献与投稿论文使用明确的来源类型和来源标识接入同一评分入口，避免复制论文实体。

## 信息架构

桌面端取消常驻左侧栏，改为三层机构式框架：

1. 黑色工具栏：机构说明、语言或帮助、账户入口。
2. 白色标识区：OpenIsle 名称、简短使命说明、搜索和主要行动入口。
3. 蓝色主导航：Papers、Knowledge Base、Reviews、Rankings、Submit。

页面底部统一提供平台说明、研究流程、使用帮助和项目链接。移动端折叠主导航，但本阶段仅保证基本可用。

## 视觉规范

- 基调参考联合国公共机构网站的信息密度与秩序，不复制其内容或标识。
- 颜色以深灰、白色和 OpenIsle 蓝为主；状态色仅用于警告、错误和成功信息。
- 页面使用清晰网格、细分隔线和充足留白；删除玻璃效果、渐变、悬浮阴影和大面积圆角卡片。
- 默认圆角为 0 至 2px；按钮、输入框和表格保持正式、紧凑。
- 标题采用编辑出版感衬线字体，正文和操作使用高可读无衬线字体。
- 状态不依赖胶囊标签表达，优先采用文字、左侧色线和表格列。
- 所有页面保留跳过导航、可见焦点、语义标题和键盘操作能力。

## 核心页面

### 投稿

- 投稿列表采用档案目录/表格结构，明确标题、版本、状态、更新时间和下一步动作。
- 新投稿与继续普通草稿的选择维持现有逻辑。
- 修订入口仅打开对应论文的修订草稿，并预填原稿内容。
- 投稿编辑、解析预览和详情使用一致的文档页结构；复杂公式、表格和双栏 PDF 继续允许作者人工校正。

### 知识库

- 文献列表展示元数据、PDF 状态、解析状态和知识提取状态。
- 文献详情集中展示摘要、全文解析、知识卡片、方法、数据点、下载与评分入口。
- 工作台在 OpenIsle 内提供在线采集、批次状态、失败原因、重新下载、重新解析、重新提炼和同步。
- 删除面向用户的“打开原系统工作台”主流程；调试链接只能存在于开发配置或管理员诊断区。

### 评分与排名

- 评分任务以正式工作队列展示，区分已有文献与投稿论文。
- 评分表单展示规则、证据和冲突声明，提交后进入评分结果与排名。
- 排行榜支持总体结果和单篇评分详情，来源清晰可追溯。

## 接口和数据约束

- 浏览器只调用 OpenIsle `/api/**`，不直连 Python 文献服务。
- 文献适配层统一返回资源标识、标题、作者、年份、PDF 状态、解析状态、提炼状态和错误信息。
- 所有管理写操作由 OpenIsle 校验登录与角色，并记录操作者和时间。
- Python 服务不可用时，页面显示明确的服务状态和可重试动作，不显示空白卡片。
- 投稿论文与已有文献必须通过 `sourceType + sourceId` 区分，评分记录不得仅依赖标题匹配。

## 实施顺序

1. 建立全局设计变量、机构式页头、横向导航和页脚。
2. 重构论文、知识库、评分排名和任务页面的公共布局与组件。
3. 删除文献核心流程的外部跳转，补齐 OpenIsle 工作台中的操作和状态反馈。
4. 校验投稿论文与已有文献进入评分任务的来源映射。
5. 运行前端构建、后端测试、文献服务测试与 API 链路回归。

## 验收标准

- 用户从登录到投稿、文献采集处理、人工评分和排名全程不离开 OpenIsle。
- 桌面端不存在常驻左侧导航、玻璃拟态、大阴影和大圆角卡片。
- Papers、Knowledge Base、Reviews、Rankings、Submit 使用同一页头、导航、页脚和状态表达。
- 文献采集、PDF 处理、知识提取、失败重试和检索都有 OpenIsle 页面入口。
- 评分任务能明确处理已有文献；投稿论文的来源和存储边界不混淆。
- 前端生产构建通过，相关后端与文献服务测试通过，核心 API 自动化回归通过。
