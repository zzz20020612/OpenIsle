# 维度8: 语言引用分析器

## 检查项
1. 摘要可读性
2. 语法错误密度
3. DOI/PMID 校验
4. 自引率
5. 引用准确性

## 执行逻辑
1. **评估摘要可读性**：使用 LLM 评估摘要的语言质量（语法、用词、连贯性）
2. **提取参考文献**：从 segments 中提取参考文献列表
3. **校验 DOI/PMID**：
   - DOI 格式：`/10\.\d{4,}/` 验证格式有效性
   - PMID 格式：`/\d+/` 验证是否在 PubMed 范围内
4. **统计自引率**：检查作者姓名在参考文献中出现的比例
   - 自引率 < 10% → 正常
   - 自引率 10%~20% → 需关注
   - 自引率 > 20% → 标记为 warning
5. **检查引用准确性**：抽查 3~5 条引用，验证标题/作者/年份是否匹配

## 推理链
1. **摘要可读性评估**：使用 LLM 评估语法、用词、连贯性（1-5 分制）
2. **参考文献提取**：从 segments 中提取参考文献列表，解析编号/DOI/标题
3. **DOI/PMID 校验**：格式验证 + 有效性检查（API 查询确认 DOI 存在）
4. **自引率计算**：检查作者姓名在参考文献中出现的比例
5. **引用准确性抽检**：抽查 3~5 条引用，验证标题/作者/年份是否匹配
6. **综合判定**：DOI 无效 ≥ 3 → failed；自引率 > 20% → warning(major)；语法差 → warning(minor)

**共识 vs 分歧量化（借鉴 PaperDecision）**：
- 若 >50% 引用缺少 DOI → 可能是掠夺性期刊引用模式 → 升级为 warning(major)
- 若自引率 > 20% 且引用总数 < 15 → 高度可疑 → 标记为 interaction_needed

## 判定标准
| 指标 | passed | warning | failed |
|------|--------|---------|--------|
| 摘要可读性 | 优秀 | 一般 | 差 |
| 语法错误 | 0~2 处 | 3~5 处 | > 5 处 |
| DOI 有效性 | 全部有效 | 1~2 个无效 | ≥ 3 个无效 |
| 自引率 | < 10% | 10%~20% | > 20% |

## 常见误判
- **误判1**: 非英语期刊的引用格式被标记为不一致 → 不同期刊的引用格式标准不同，应确认目标期刊要求
- **误判2**: 预印本被标记为引用质量低 → 预印本在正式发表前DOI可能尚未被收录，需确认是否为正式发表文献
- **误判3**: 小众领域的高自引率被标记为异常 → 小众领域研究者少，高自引率可能是正常现象，需人工判断
