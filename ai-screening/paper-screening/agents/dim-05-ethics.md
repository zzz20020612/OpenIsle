# 维度5: 伦理法规分析器

## 检查项
1. 伦理审批信息（机构全称+批准文号）
2. 临床试验注册号
3. 动物实验声明（ARRIVE 指南）
4. 患者隐私保护
5. 伦理声明缺失

## 执行逻辑
1. **搜索伦理声明**：在全文中搜索以下关键词：
   - "伦理/ethics/IRB/ethics committee"
   - "审批/approval/批准"
   - "注册号/registration/trial"
   - "知情同意/informed consent"
2. **提取审批信息**：使用正则提取：
   - 伦理批准文号：`/\d{4}-\d{3}-\d+/` 或类似格式
   - 临床注册号：`/NCT\d+/`、`/ChiCTR\d+/` 等
3. **验证完整性**：
   - 有伦理声明 → 检查是否包含机构名称 + 批准文号
   - 无伦理声明 → 标记为 warning（部分学科可能不需要）
4. **检查隐私保护**：搜索是否提及患者知情同意

## 推理链
1. 识别研究类型（临床/动物/回顾性/综述/计算）
2. 根据研究类型确定适用的伦理要求
3. 搜索伦理审批声明
4. 验证审批信息完整性（机构+文号）
5. 检查临床试验注册（如适用）
6. 检查隐私保护声明
7. 综合判定（考虑研究类型的豁免项）

## 判定标准
| 指标 | passed | warning | failed |
|------|--------|---------|--------|
| 伦理审批 | 有完整声明 | 有声明但缺文号 | 无声明 |
| 临床注册 | 有注册号 | 有声明但缺号 | 无声明（临床研究） |
| 知情同意 | 明确声明 | 隐含提及 | 未提及 |

## 常见误判
- **误判1**: 纯计算/理论论文被要求伦理审批 → 不涉及人/动物的计算研究通常豁免伦理审批
- **误判2**: 已发表论文的二次分析被要求原始伦理审批 → 二次分析可能使用已有公开数据集，需确认数据来源
- **误判3**: 跨国合作被标记为伦理审批缺失 → 不同国家的伦理审批要求不同，需确认各国审批情况
