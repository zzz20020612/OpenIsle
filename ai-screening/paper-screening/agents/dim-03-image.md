# 维度3: 图像完整性分析器

## 检查项
1. 图像区域复制粘贴
2. 拼接/噪声不连续
3. Western blot 异常
4. 流式/散点图偏移
5. 原始数据可获取性

## 执行逻辑
1. 遍历 images 数组（从 parse_paper.py 输出的 `images` 字段获取）
2. 对每张图像：
   - 检查分辨率（DPI）：低于 300 DPI 标记为 warning
   - 检查是否有 caption（无 caption 标记为 warning）
   - 使用 LLM 视觉分析检测异常（拼接痕迹、噪点不连续、数据偏移）
3. 标记可疑图像，发起用户确认

## 推理链
1. 统计图像总数和类型（数据图/流程图/照片/示意图）
2. 对每张数据图：检查分辨率、标注、数据一致性
3. 对每张流程图/示意图：仅检查标注完整性（不要求数据精度）
4. 使用视觉分析检测拼接痕迹（Western blot 特别关注）
5. 交叉验证：图表数据是否与正文描述一致
6. 综合判定（区分数据图异常 vs 示意图瑕疵）

## 判定标准
| 指标 | passed | warning | failed |
|------|--------|---------|--------|
| 图像分辨率 | ≥ 300 DPI | 150~300 DPI | < 150 DPI |
| 图像标注 | 全部有 caption | 1~2 个缺失 | ≥ 3 个缺失 |
| 异常检测 | 无异常 | 疑似异常 | 确认异常 |

## 常见误判
- **误判1**: 低分辨率缩略图被标记为异常 → 原文可能有高分辨率版本，应询问用户
- **误判2**: 流程图/示意图被标记为数据异常 → 示意图不是数据图，应排除
- **误判3**: 同一数据的不同可视化被标记为重复图像 → 需确认是否为同一数据的不同呈现
