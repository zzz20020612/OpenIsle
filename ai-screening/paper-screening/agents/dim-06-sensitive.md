# 维度6: 敏感内容分析器

## 检查项
1. 地图边界（九段线/海岸线）
2. 领土表述规范（台湾/香港/澳门）
3. 民族宗教歧视
4. 管控材料许可

## 实现方案
**文本层检查**（规则引擎）：
- 敏感词库匹配
- "台湾" → 检查是否加"中国"限定（必须为"中国台湾"或"台湾地区"）
- "香港/澳门" → 检查是否加"中国"限定（必须为"中国香港"/"中国澳门"）
- 搜索敏感词列表：台湾、香港、澳门、西藏、新疆、南海、九段线、钓鱼岛

**图像层检查**（模板比对）：
- 检测地图插图（搜索含 "map/地图/figure" 的 segments）
- 与天地图标准模板比对
- LLM 辅助判断地图是否完整

## 执行逻辑
1. 在全文中搜索敏感词列表（使用 `check_sensitive.py` 脚本）
2. 脚本自动完成：领土限定词检查 + 绝对违规词汇检测
3. agent 补充检查：民族宗教歧视内容（脚本未覆盖）、管控材料许可（脚本未覆盖）
4. 输出所有发现

## 输出
```json
{
  "dimension_id": "06",
  "dimension_name": "敏感内容",
  "status": "passed|warning|failed",
  "severity": "info|minor|major|critical",
  "findings": [
    {
      "item": "领土表述",
      "actual": "发现「台湾」未加「中国」限定",
      "suggestion": "改为「中国台湾」或「台湾地区」"
    }
  ],
  "interaction_needed": true
}
```

## 推理链
1. **绝对违规词扫描**：搜索 "台湾独立/藏独/疆独/港独" 等零容忍词汇 → 任何命中直接 failed
2. **领土限定词检查**："台湾" → 必须为"中国台湾"或"台湾地区"；"香港/澳门" → 必须加"中国"前缀
3. **上下文语义判断**：排除学术引用中的敏感词（如引用原文）、机构名称（如"台湾大学"）
4. **地图完整性检测**：检查是否有地图图片 → 需与天地图标准模板比对
5. **民族宗教歧视扫描**：搜索歧视性表述 → 人工审核确认
6. **综合判定**：绝对违规 → failed(critical)；领土表述不规范 → warning(major)；其他 → warning(minor)

**视觉偏见穿透（借鉴 PaperDecision）**：
- 若论文包含地图类图片 → 强制要求与天地图标准模板逐项比对
- 不能仅凭文字描述判断地图完整性 → 必须有视觉证据

## 判定标准
| 指标 | passed | warning | failed |
|------|--------|---------|--------|
| 绝对违规词 | 无 | — | 任何命中 |
| 领土限定词 | 全部合规 | 1~2 处不规范 | ≥ 3 处违规 |
| 地图完整性 | 无地图/完整 | 疑似不完整 | 确认缺失 |
| 歧视内容 | 无 | 疑似（需人工确认） | 确认违规 |

## 常见误判
- **误判1**: "台湾大学"被标记为领土表述问题 → 这是机构名称，不是领土表述，应排除
- **误判2**: 学术引用中的敏感词被标记为违规 → 引用原文中的敏感词是学术引用，应排除
- **误判3**: 地图图片被误判为不完整 → 需要与天地图模板比对，不能仅凭文字描述判断
